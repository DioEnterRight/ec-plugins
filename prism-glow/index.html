Install the plug-in

The download is one zip. Inside are INSTALL_WINDOWS.bat, a 1_Plugin folder, a source folder and an INSTALL.txt with these same steps. There is only one file to install. Unzip the whole zip first. Don't run anything from inside the zip.

Fastest on Windows: double-click the installer

Inside the unzipped folder, double-click INSTALL_WINDOWS.bat. It makes the Plug-ins folder if it is missing and copies the plug-in. Then restart EffectCraft. If Windows asks whether to run the file, click Run.

Or install by hand

EffectCraft doesn't make the Plug-ins folder for you. If it isn't there, make it yourself. It must be named exactly Plug-ins, with a capital P and a dash.

  1. Open File Explorer. Click the address bar, type %APPDATA% and press Enter.
  2. Open the EffectCraft folder. If there isn't one, start EffectCraft once and close it, or make a folder named EffectCraft.
  3. Inside it, make a new folder named Plug-ins.
  4. Copy 1_Plugin\ec_prism_glow.wasm into that folder.
  5. Restart EffectCraft. It loads every .wasm file in that folder when it starts. Search for EC Prism Glow in Effects & Presets. It sits under Stylize.

The full Plug-ins folder for each system:

Windows

%APPDATA%\EffectCraft\Plug-ins

macOS

~/Library/Application Support/EffectCraft/Plug-ins

Linux

~/.config/effectcraft/Plug-ins

On macOS or Linux, run this in Terminal inside the unzipped folder. It makes the folder and copies the file:

macOS

mkdir -p ~/Library/Application\ Support/EffectCraft/Plug-ins && cp 1_Plugin/ec_prism_glow.wasm ~/Library/Application\ Support/EffectCraft/Plug-ins/

Linux

mkdir -p ~/.config/effectcraft/Plug-ins && cp 1_Plugin/ec_prism_glow.wasm ~/.config/effectcraft/Plug-ins/

On the Windows portable build, use EffectCraftData\Plug-ins next to EffectCraft.exe. The installer is for the normal installed EffectCraft only.

Want to try it before copying anything? Choose Effect > Load Effect Plug-in… and pick ec_prism_glow.wasm. It loads right away.

Add it to a layer

  1. Select a layer that has bright parts: lights, highlights, or bright text on black.
  2. Double-click EC Prism Glow in Effects & Presets. You can also drag it onto the layer.
  3. Change the controls in Effect Controls. The next section shows the four to start with.

Nothing needs an expression and there are no presets to install. It glows right away with the defaults.

The four main controls

Brightness2Overall glow strength. Raise it for more glow.
Threshold0.5Which pixels start the glow. Lower it to glow more of the picture.
Glow Width0.4How wide the glow spreads, as a fraction of the frame.
CombineScreenHow the glow combines with the picture. Screen is HDR-safe and the default.

Not sure which pixels are glowing? Set Show to Threshold to see them, then set it back to Result.

How it works

EC Prism Glow builds a stack of progressively larger gaussian blurs (an octave pyramid) and sums them with falling weight per octave, approximating the long soft power-law falloff of real light scatter — a bright core with a long, dim tail, rather than a single blurred blob.

Width Red, Width Green and Width Blue scale the spread per channel, which is what gives the glow a soft colored fringe at its edges instead of a flat white halo. Width X and Width Y stretch the glow horizontally or vertically.

Light Background switches the compositing model for glowing onto a bright background instead of a dark one, and when it's on, Combine has no effect — the two are alternate ways of laying the glow over the source, not a stack.

Speed and quality

EC Prism Glow runs on the CPU inside EffectCraft's plug-in sandbox, which is an interpreter, so it is slower than a native plug-in. In testing on a server, a 1080p frame at default settings took under 200 ms. Your machine will differ.

  • Preview at half or quarter resolution while you design.
  • A bigger Glow Width costs more, because it widens every octave of the blur pyramid.
  • Atmosphere Amp above 0 adds a noise pass; leave it at 0 for the cheapest render.

Save your own preset

The Presets folder isn't there until you make it. Installing EffectCraft doesn't create it. EffectCraft reads presets from exactly this folder:

Windows

%USERPROFILE%\Documents\EffectCraft\Presets

macOS

~/Documents/EffectCraft/Presets

Linux

~/Documents/EffectCraft/Presets

On Windows that means C:\Users\<your user name>\Documents\EffectCraft\Presets.

Make the Presets folder on Windows

  1. Open File Explorer. Click the address bar, type %USERPROFILE% and press Enter. You're now in C:\Users\<your user name>.
  2. Open Documents. If there's no Documents folder there, make one named Documents.
  3. Inside Documents, make a new folder named EffectCraft.
  4. Inside EffectCraft, make a new folder named Presets.

OneDrive: even if Windows keeps your Documents in OneDrive, EffectCraft still looks in C:\Users\<you>\Documents, not in OneDrive\Documents. Step 1 takes you to the right place.

To check, open the Effects & Presets panel menu, choose Copy Presets Folder Path, and paste it into the File Explorer address bar. That's the folder EffectCraft reads.

On macOS or Linux, this Terminal line makes it:

macOS / Linux

mkdir -p ~/Documents/EffectCraft/Presets

Save it

  1. Set up EC Prism Glow on a layer the way you like it.
  2. Select EC Prism Glow in Effect Controls.
  3. Choose Animation > Save Animation Preset… and save the file in the Presets folder.
  4. In the Effects & Presets panel menu, choose Refresh List. Your preset shows up under * Animation Presets.

If something goes wrong

There is no glow on a frame.
Lower Threshold, raise Brightness, or check the layer actually has bright pixels. Set Show to Threshold to see exactly what passes.
The atmosphere texture doesn't move.
Add the expression time - thisLayer.startTime to Time (s). See the Animation row under Controls.
The Mocha mask block does nothing.
Expected — EffectCraft's plug-in format has no tracking-mask input. See "What this is and isn't" below.
EC Prism Glow isn't in the Effects list.
The Plug-ins folder must exist and be named exactly Plug-ins. See Install the plug-in, then restart EffectCraft. The effect is under Stylize. The web version of EffectCraft can't run plug-ins.
I see "an effect with this id is already registered".
The plug-in is already loaded, usually because it is in the Plug-ins folder and you also loaded it from the menu. Nothing to fix.

What this is and isn't

  • Close by design, not pixel-proven. Every control name, default, range and declaration order follows Sapphire's S_Glow panel. The render math (multi-octave gaussian pyramid, power-law falloff, HDR-safe Screen blend) was built and checked against Boris FX's own published description of S_Glow's documented behavior, with an automated test for each documented claim. It has not been compared pixel-for-pixel against a real Sapphire render.
  • Independent. Contains no Boris FX code or assets, and isn't affiliated with or endorsed by Boris FX. The name "S_Glow" is used only to say what this plug-in is modeled on.
  • No tracking-mask input. EffectCraft's plug-in format can't take a Mocha tracking project as an input, so the whole Mocha Mask block is declared (to keep the exact control layout) but does nothing.
  • Expand Borders, Invert Mask and Show Glow Width are inert for the same reason: they depend on reading extra border pixels or a separate mask layer, which EffectCraft's plug-in format doesn't expose.
  • CPU only. Runs in EffectCraft's interpreted plug-in sandbox.
  • Desktop and CLI. EffectCraft's web version can't run plug-ins.
