Install the plug-in

The download is one zip. Unzip it and you get a 1_Plugin folder, a 2_Presets folder and an INSTALL.txt with these same steps.

  1. Copy 1_Plugin/ec_twitch.wasm into EffectCraft's Plug-ins folder for your system. Create the folder if it isn't there yet.
  2. Restart EffectCraft. It loads every .wasm file in that folder when it starts.
  3. Open Effects & Presets and search for EC Twitch. It sits under Stylize.

Windows

%APPDATA%\EffectCraft\Plug-ins

macOS

~/Library/Application Support/EffectCraft/Plug-ins

Linux

~/.config/effectcraft/Plug-ins

On the Windows portable build, the folder is EffectCraftData\Plug-ins next to EffectCraft.exe.

Want to try it before copying anything? Choose Effect > Load Effect Plug-in… and pick ec_twitch.wasm. It loads right away.

Add the presets

  1. Copy every file from 2_Presets into EffectCraft's Presets folder. Put the files directly in the folder, not in a subfolder.
  2. In Effects & Presets, open the panel menu and choose Refresh List. Check that Show Animation Presets is ticked.
  3. Look under * Animation Presets. Every preset is named EC Twitch - ….

Windows

%USERPROFILE%\Documents\EffectCraft\Presets

macOS

~/Documents/EffectCraft/Presets

Linux

~/Documents/EffectCraft/Presets

Not sure where your Presets folder is? In Effects & Presets, open the panel menu and choose Copy Presets Folder Path. If you set the EC_PRESETS_DIR environment variable, EffectCraft uses that folder instead.

Apply a preset

  1. Select a layer.
  2. Move the playhead to where the twitch should start.
  3. Double-click a preset in Effects & Presets. You can also drag it onto a layer, or choose Animation > Apply Animation Preset… and pick the file.

EC Twitch now shows in Effect Controls. Change Amount and Speed to taste, and change Seed to get a different random pattern. The same Seed always gives the same result, on any machine.

Transition presets

Presets that start with Transition carry keyframes on Amount that fade the twitch in and out over 0.4 seconds from the playhead. The peak lands 0.2 seconds in, so start about 6 frames before your cut.

Each preset adds a new EC Twitch effect. To swap presets, delete the old EC Twitch first. One undo removes a whole preset.

Adding the effect from the Effects menu

If you add EC Twitch without a preset, two parameters need an expression. Presets add them for you.

  • Time (s): time - thisLayer.startTime
  • Frame Rate: 1 / thisComp.frameDuration

Select the parameter, choose Animation > Add Expression and paste the line. Without the first one, EffectCraft renders a single frame and the effect looks frozen.

Use the Time operator

Time shifts the footage forward or back by whole frames. EffectCraft's plug-in format can't read other frames, so Time runs as an expression on Time Remap. It uses the same random schedule as the effect, so it stays in step with the other operators.

  1. Use a footage layer or a pre-comp. A solid can't be time-remapped. Layer > Pre-compose turns any layer into a pre-comp.
  2. Choose Layer > Time > Enable Time Remapping.
  3. Apply EC Twitch - Time Stutter, Rewind Glitch or Total Chaos.

Applying one of these replaces the layer's Time Remap keyframes. If the layer isn't time-remapped yet, the effect still applies but the Time part is skipped.

Already have EC Twitch on the layer? Tick Time in its Enable controls, then apply EC Twitch - Time Remap. That preset adds only the Time Remap expression. Don't rename the EC Twitch effect, because the expression finds it by name.

How it works

Each operator fires random twitches. One twitch builds up over Ease In frames, holds for Hold Frames, then fades over Ease Out frames. Its size is random between Randomize Minimum and full strength, scaled by Amount.

How often an operator fires is Speed times that operator's Twitches [sec]. Speed 2 with Twitches 1 means two twitches every second.

Operators with Unique Seed at 0 share one timing pattern, so operators with the same rate fire on the same frame. Give an operator its own Unique Seed to split its timing from the rest.

Nothing carries over between frames. Each frame is worked out from the Seed and the time alone, so you can scrub, jump around or render in any order and get the same picture.

Speed and quality

EC Twitch runs on the CPU inside EffectCraft's plug-in sandbox. In testing on a cloud server, a 1080p frame with one operator twitching took about 0.5 to 1.4 seconds, and about 3.5 seconds with all of them on. Your machine will differ. Frames where nothing is twitching cost almost nothing.

  • Set Quality to Draft while you design.
  • Preview at half or quarter resolution.
  • Big blurs cost the same as small ones. The cost comes from the number of motion-blur samples and the frame size.
  • If a frame ever fails to render, EffectCraft leaves it unchanged instead of crashing.

Save your own preset

  1. Set up EC Twitch on a layer the way you like it.
  2. Select EC Twitch in Effect Controls.
  3. Choose Animation > Save Animation Preset… and save the file in your Presets folder.

It then shows up in the panel next to the others. Saving keeps the two expressions, so your preset animates right away.

If something goes wrong

The effect looks frozen on one frame.
The Time (s) parameter needs its expression. See "Adding the effect from the Effects menu" above.
My presets aren't listed.
The files must sit directly inside the Presets folder, with the .ecpreset ending. Choose Refresh List in the panel menu and check that Show Animation Presets is ticked.
EC Twitch isn't in the Effects list.
Check the Plug-ins folder path for your system and restart EffectCraft. The effect is under Stylize. The web version of EffectCraft can't run plug-ins.
I see "an effect with this id is already registered".
The plug-in is already loaded, usually because it is in the Plug-ins folder and you also loaded it from the menu. Nothing to fix.
Time does nothing.
Enable Time Remapping on the layer first, then apply a Time preset. Tick Time in the effect's Enable controls.
Playback is slow.
Use Draft quality and a lower preview resolution. See "Speed and quality".

What this is and isn't

  • Close, not identical. The controls, options and the idea of random twitches with eased in and out times follow Video Copilot's public descriptions of Twitch. Video Copilot doesn't publish the math. How far a slide moves or how bright a flash gets is tuned by eye, not matched to After Effects renders.
  • Independent. It contains no Video Copilot code or assets, and it isn't affiliated with or endorsed by Video Copilot.
  • CPU only. Heavy frames can take seconds at full size.
  • One flat list of controls. No fold-out groups yet.
  • Time needs a footage or pre-comp layer with Time Remapping on.
  • Desktop and CLI. EffectCraft's web version can't run plug-ins.
  • You get 25 presets. Twitch's sound effects and video tutorials aren't included.
