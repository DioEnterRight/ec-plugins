How you get a plug-in

  1. Download the zipOne file per plug-in. It has the plug-in, instructions and license inside.
  2. Copy one filePut the .wasm file in EffectCraft's Plug-ins folder and restart EffectCraft.
  3. Find it under StylizeSearch for the name in Effects & Presets and apply it to a layer.

Questions

Is it free?
Yes. You can use both plug-ins in your own work, including paid work. You can't redistribute or resell them.
Where do the download, like and comment numbers come from?
From this project's GitHub page. Downloads are GitHub's own count of the zip. Likes are thumbs-up, heart, party and rocket reactions on the plug-in's GitHub thread, and comments are the comments on it. Liking and commenting need a free GitHub account.
Does it work in the web version of EffectCraft?
No. Plug-ins run in the desktop app and the command line.
Is EC Twitch the same as Video Copilot's Twitch, and is EC Deep Glow 2 the same as Deep Glow 2?
No. They are independent plug-ins built from public descriptions and are close in idea, not proven identical. Each page says what is and isn't there.
