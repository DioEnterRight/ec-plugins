EC Deep Glow 2

Makes the bright parts of your picture glow like real light: a hot core and a long soft halo. It works in HDR, so values brighter than white keep glowing instead of clipping.

Install the plug-in

The download is one zip. Unzip it and you get a 1_Plugin folder and an INSTALL.txt with these same steps. There is only one file to install.

  1. If you have an older deep_glow_open_*.wasm in your Plug-ins folder, delete it. Otherwise you will see two glow effects.
  2. Copy 1_Plugin/ec_deep_glow_2.wasm into EffectCraft's Plug-ins folder for your system. Create the folder if it isn't there yet.
  3. Restart EffectCraft. It loads every .wasm file in that folder when it starts.
  4. Open Effects & Presets and search for EC Deep Glow 2. It sits under Stylize.

Windows

%APPDATA%\EffectCraft\Plug-ins

macOS

~/Library/Application Support/EffectCraft/Plug-ins

Linux

~/.config/effectcraft/Plug-ins

On the Windows portable build, the folder is EffectCraftData\Plug-ins next to EffectCraft.exe.

Want to try it before copying anything? Choose Effect > Load Effect Plug-in… and pick ec_deep_glow_2.wasm. It loads right away.

Add it to a layer

  1. Select a layer that has bright parts: lights, highlights, or bright text on black.
  2. Double-click EC Deep Glow 2 in Effects & Presets. You can also drag it onto the layer.
  3. Change the controls in Effect Controls. The next section shows the four to start with.

Nothing needs an expression and there are no presets to install. It glows right away with the defaults.

The four main controls

ControlDefaultWhat to do with it
Threshold35Lower it to glow more of the picture. Raise it so only the brightest parts glow. Above 100 only HDR super-whites glow.
Radius300How far the glow spreads, in pixels. A bigger radius gives a wider and dimmer glow, because the glow only moves light around.
Exposure1.5Glow brightness in stops. Each +1 doubles the glow.
Intensity100Glow strength in percent, on top of Exposure.

Not sure which pixels are glowing? Set View to Threshold Matte to see them, then set it back to Composite.

How it works

EC Deep Glow 2 picks the bright pixels, spreads their light outward, and adds it back over the picture. The spread follows the law of real light: a hot core and a long, soft tail. Radius is how far the tail reaches and Falloff is how fast it fades.

The glow only moves light around. It never adds or loses any, so the total brightness stays the same as you change the radius. That is why a big radius looks dimmer: the same light covers more area. Raise Exposure to bring it back up.

It works in HDR. Pixels brighter than white keep their full brightness and keep glowing, instead of being cut off at white.

Speed and quality

EC Deep Glow 2 runs on the CPU inside EffectCraft's plug-in sandbox. In testing on a server, a 1080p frame took about 0.8 seconds with the default settings and about 0.4 seconds in Draft. A 4K frame at Medium took about 1.7 seconds. A stretched and rotated glow took about 2 seconds at 1080p, and Lens Iris at High sampling about 5 seconds. Your machine will differ.

  • Set Quality to Draft while you design.
  • Preview at half or quarter resolution.
  • If a frame is too heavy for the plug-in sandbox, EffectCraft shows it without glow instead of crashing. Lower Quality, Radius or Iris Sampling Quality.
  • A 4K frame with a rotated glow needs close to 1 GB of plug-in memory, which is the sandbox limit.

Save your own preset

  1. Set up EC Deep Glow 2 on a layer the way you like it.
  2. Select EC Deep Glow 2 in Effect Controls.
  3. Choose Animation > Save Animation Preset… and save the file in your Presets folder.

If something goes wrong

There is no glow on a frame.
The frame may be too heavy for the plug-in sandbox. Lower Quality, Radius or Iris Sampling Quality. Or lower Threshold so some pixels pass it. Set View to Threshold Matte to check.
I see two glow effects in the list.
Delete the old deep_glow_open_*.wasm from the Plug-ins folder and restart.
EC Deep Glow 2 isn't in the Effects list.
Check the Plug-ins folder path for your system and restart EffectCraft. The effect is under Stylize. The web version of EffectCraft can't run plug-ins.
I see "an effect with this id is already registered".
The plug-in is already loaded, usually because it is in the Plug-ins folder and you also loaded it from the menu. Nothing to fix.
The glow looks too dim or too bright.
Change Exposure first. Each +1 doubles it. A bigger Radius spreads the same light over more area, so raise Exposure to match.
The aperture shape looks round.
Blade shapes show most clearly at Standard and High sampling. At Low sampling, and in the far tail of very large radii, the aperture fades to a circle.

What this is and isn't

  • Close, not proven identical. It has every control that Deep Glow 2 documents, except the few listed below. Nobody has compared its numbers with real Deep Glow 2 renders yet, so treat the exact look as close in idea.
  • Independent. It was built from public documentation and observed behavior. It contains no code or assets from Deep Glow 2 and isn't affiliated with or endorsed by its makers.
  • No picture-layer inputs. EffectCraft's plug-in format can't take layer inputs, so Mask, Iris and Lens Dirt layers aren't there. The plug-in draws its own aperture and dirt instead. Buffer Expansion, grouped panels and buttons are missing for the same reason.
  • CPU only. Heavy frames can take seconds at full size.
  • Desktop and CLI. EffectCraft's web version can't run plug-ins.
