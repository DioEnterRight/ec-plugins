Install the plug-in

The download is one zip. Inside are INSTALL_WINDOWS.bat, a 1_Plugin folder, a CHANGELOG.txt and an INSTALL.txt with these same steps. There is only one file to install. Unzip the whole zip first. Don't run anything from inside the zip.

Fastest on Windows: double-click the installer

Inside the unzipped folder, double-click INSTALL_WINDOWS.bat. It makes the Plug-ins folder if it is missing and copies the plug-in. Then restart EffectCraft. If Windows asks whether to run the file, click Run.

Or install by hand

EffectCraft doesn't make the Plug-ins folder for you. If it isn't there, make it yourself. It must be named exactly Plug-ins, with a capital P and a dash.

  1. Open File Explorer. Click the address bar, type %APPDATA% and press Enter.
  2. Open the EffectCraft folder. If there isn't one, start EffectCraft once and close it, or make a folder named EffectCraft.
  3. Inside it, make a new folder named Plug-ins.
  4. Copy 1_Plugin\ec_outline_glow.wasm into that folder.
  5. Restart EffectCraft. It loads every .wasm file in that folder when it starts. Search for Outline Glow in Effects & Presets. It sits under Stylize.

The full Plug-ins folder for each system:

Windows

%APPDATA%\EffectCraft\Plug-ins

macOS

~/Library/Application Support/EffectCraft/Plug-ins

Linux

~/.config/effectcraft/Plug-ins

On macOS or Linux, run this in Terminal inside the unzipped folder. It makes the folder and copies the file:

macOS

mkdir -p ~/Library/Application\ Support/EffectCraft/Plug-ins && cp 1_Plugin/ec_outline_glow.wasm ~/Library/Application\ Support/EffectCraft/Plug-ins/

Linux

mkdir -p ~/.config/effectcraft/Plug-ins && cp 1_Plugin/ec_outline_glow.wasm ~/.config/effectcraft/Plug-ins/

On the Windows portable build, use EffectCraftData\Plug-ins next to EffectCraft.exe. The installer is for the normal installed EffectCraft only.

Want to try it before copying anything? Choose Effect > Load Effect Plug-in… and pick ec_outline_glow.wasm. It loads right away.

Add it to a layer

  1. Select your layer. Text, shapes, logos and footage with clear edges work best.
  2. Double-click Outline Glow in Effects & Presets, under Stylize. You can also drag it onto the layer.
  3. The glow shows on the edges of your layer, on top of the layer itself.
Start withDefaultWhat to do with it
Glow Strength65Brightness of the glow.
Glow Spread36How far the glow reaches from the edge.
Edge Threshold18Lower it if some edges don't glow. Raise it if too much of the picture glows.
Glow TypeNeonThe pattern. See Glow Types below.
Glow Colour 1CyanThe glow's colour. Tick Use Custom Multicolour to blend in Glow Colour 2 and 3.

Not sure what it picks up? Set View to Edge Map, then set it back to Final.

Make it animate

The flicker and moving styles don't move on their own. EffectCraft only re-renders a plug-in when one of its settings changes, so it needs a clock. Do this once on every layer you use it on.

  1. In Effect Controls, find Animation Time (s), at the bottom of the list.
  2. Select it and choose Animation > Add Expression.
  3. Paste this line exactly:

Expression

time - thisLayer.startTime

Now the flicker and styles move when you play the timeline. Without it, the glow stays frozen on one look.

Glow Types

Glow Type changes the pattern and movement of the glow, not its colours. The colours always come from Glow Colour 1, 2 and 3. Style Intensity, Style Scale and Style Speed tune each type.

TypeWhat it looks like
NeonA clean, steady neon tube.
ElectricA crackling, wobbling edge with sparks in the glow. The slowest to render.
WaterThe edge ripples in waves.
GalaxySmall stars twinkle in the glow.
IceThe glow breaks into frosty facets.
FireThe edge flickers and the glow rises upward.
PlasmaBands of light move through the glow. With Use Custom Multicolour on, the colours shift too.

Speed

In testing, a 1080p frame took about 0.7 seconds in a browser's engine. Inside EffectCraft it can be slower. Electric is the slowest style, at about twice the cost of Neon. Preview at half resolution while you design.

Save your own preset

The Presets folder isn't there until you make it. Installing EffectCraft doesn't create it. EffectCraft reads presets from exactly this folder:

Windows

%USERPROFILE%\Documents\EffectCraft\Presets

macOS

~/Documents/EffectCraft/Presets

Linux

~/Documents/EffectCraft/Presets

On Windows that means C:\Users\<your user name>\Documents\EffectCraft\Presets.

Make the Presets folder on Windows

  1. Open File Explorer. Click the address bar, type %USERPROFILE% and press Enter. You're now in C:\Users\<your user name>.
  2. Open Documents. If there's no Documents folder there, make one named Documents.
  3. Inside Documents, make a new folder named EffectCraft.
  4. Inside EffectCraft, make a new folder named Presets.

OneDrive: even if Windows keeps your Documents in OneDrive, EffectCraft still looks in C:\Users\<you>\Documents, not in OneDrive\Documents. Step 1 takes you to the right place.

To check, open the Effects & Presets panel menu, choose Copy Presets Folder Path, and paste it into the File Explorer address bar. That's the folder EffectCraft reads.

On macOS or Linux, this Terminal line makes it:

macOS / Linux

mkdir -p ~/Documents/EffectCraft/Presets

Save it

  1. Set up Outline Glow on a layer the way you like it.
  2. Select Outline Glow in Effect Controls.
  3. Choose Animation > Save Animation Preset… and save the file in the Presets folder.
  4. In the Effects & Presets panel menu, choose Refresh List. Your preset shows up under * Animation Presets.

If something goes wrong

The glow doesn't flicker or move.
Add the expression from Make it animate to Animation Time (s).
There's no glow at all.
Lower the threshold, raise Glow Strength, and check that View is set to Final. Set View to Edge Map to see which edges it finds.
Outline Glow isn't in the Effects list.
The Plug-ins folder must exist and be named exactly Plug-ins. See Install the plug-in, then restart EffectCraft.
I see "an effect with this id is already registered".
The plug-in is already loaded, usually because it is in the Plug-ins folder and you also loaded it from the menu. Nothing to fix.
The glow is too strong on bright footage.
Set Glow Operation to Screen, or lower Glow Strength.
It doesn't work in the web version.
EffectCraft's web version can't run plug-ins. Use the desktop app or the CLI.

About this build

Outline Glow is made by Slizzy and upgraded by DioEnterRight. Old projects still load, because the original controls keep their order and defaults and every new control comes after them.

  • Fixed: renders that could hang or crash with extreme settings, line width that changed with the composition's resolution, hard stair-stepped lines, glow that wrapped around the layer edges, and memory that ran out at higher resolutions.
  • Added: Edge Source, Glow Side, Glow Operation, Falloff, Aspect, Core Colour, Colour Mode, Flicker Rate, Seed, View and Animation Time (s).
  • Not tested inside EffectCraft yet: the flicker animation with the expression above. It was tested in the same plug-in sandbox EffectCraft uses, outside the app.
